# Guilherme Bresolin #109

Site oficial do piloto de motocross Guilherme Bresolin. A página reúne a temporada atual, história, títulos, participação no Motocross das Nações, galeria e canais de contato.

## Desenvolvimento local

Requisitos: Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

O servidor de desenvolvimento fica disponível em `http://localhost:3000`. Para testar em outro dispositivo na mesma rede, use o endereço de rede exibido pelo terminal.

## Validação

```bash
npm run lint
npm run build
npm audit
```

## Tecnologias

- React 19
- Vinext
- Vite
- TypeScript
- CSS responsivo

## Privacidade

O formulário de contato abre o aplicativo de e-mail do visitante e não armazena as mensagens no site. O único cookie próprio é funcional e registra a escolha feita no aviso de cookies.
